# Задание №22 для локального Claude (стенд awm.local): выкладка 09595ca и повторная сверка Web

**Цель:** выложить одной сборкой исправления №62–72 и остаток сверки с макетами C53; проверить их на стенде.
**Правила — как всегда:** sudo и изменения на узлах — только с «да» пользователя; DC — только чтение; ничего вне
10.170.108.0/24; пароли в чат, отчёт и файлы не попадают.

## 1. Сборка
Коммит выкладки — `09595ca` (develop) или следующий за ним коммит только с документами, если CI surveyscan-v2,
surveyscan-web и surveyscan-boot на нём зелёные. Миграций не прибавилось (75). Rust-агенты и portable не трогать.
Контракт W2 дополнен необязательным полем `installed_name` — `npm run generate` обязателен.

## 2. Обновление (с «да»)
Копия БД (`pg_backup.py backup`, без остановки центра) → центр до коммита выкладки → Web
(`npm ci && npm run generate && npm run build`), `version.json` = sha. В журнале — без ошибок.
В Оргструктуре переименовать команду «fallback» в «Резерв площадки» (имя из тестовой заготовки стенда).

## 3. Проверка №62–72 (каждый — «да/нет» и скриншот)
62 «Хосты вне систем» и меню «Хосты» = 6 (выведенный 9252d8db не виден). 63 карточка .5 — нет «цель отключена».
64 Схема сети L3 — карта на всю ширину, без KPI и легенды. 65 нет подсетей 172.17/172.18 и «конфликтов IP».
66 обращения/календарь/склад — имя хоста вместо UID; история — без кодов MANUAL_ASSIGNMENT; журнал — «Привязан актив».
67 флажки SLA и «Новый получатель» — в строку с подписью. 68 ПО/Сеть карточки .5 — «SSH через collector».
69 Portable — «Последняя загрузка» с датой 19.11. 70 Хосты — колонка «Данные» 9/12 и т. п. 71 Источники — без
повторяющейся подписи. 72 мастер, шаг 3 — поля правила видны без прокрутки.

## 4. Сверка с макетами — остаток
Пройти все вкладки (как в №21) и отметить по `docs/plans/surveyscan-v2/handoffs/c53-web-audit-20-11.md`, раздел
«Доделано после №21»: исправлено / осталось / новое. Дополнительно: поиск «10.170.108» с фильтрами «Площадка» и
«Состояние»; «Сохранить черновик» в мастере (сохранить, уйти, вернуться — поля на месте; систему не создавать).

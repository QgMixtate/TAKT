# Задание №21 для локального Claude (стенд awm.local): выкладка a98b8a4, полная копия, сверка Web с макетами

**Цель:** выложить сборку с первой пачкой правок по макетам C53 (`ca5d7c4`) и исправлением копии (ISSUES №61,
`a98b8a4`); снять полную копию стенда; пройти все вкладки нового Web в браузере и сравнить с макетами.

**Правила — как всегда:** sudo и изменения на узлах — только с «да» пользователя (на эту выкладку «да» дано 20.11);
DC — только чтение; ничего вне 10.170.108.0/24; пароли в чат, отчёт и файлы не попадают.

## 1. Сборка
Коммит выкладки — `a98b8a4` (develop) или следующий за ним коммит только с документами, если CI surveyscan-v2 на нём **зелёный** (web и boot зелёные на `ca5d7c4`;
`a98b8a4` меняет только `scripts/checkpoint.py` и ISSUES). Если v2 красный — остановиться и прислать ссылку на прогон.
Миграций не прибавилось (75). Rust-агенты и portable не трогать.

## 2. Обновление центра и Web
1. Копия БД перед обновлением — как в №20 (`pg_backup.py backup`, без остановки центра) — путь в отчёт.
2. Центр до `a98b8a4` (OPERATIONS §2), Web — `npm ci && npm run generate && npm run build`, `version.json` = a98b8a4.
3. В журнале центра после старта — без ошибок `rsm state` / `host registry`.

## 3. Полная копия стенда (ISSUES №61)
1. В `surveyscan-stand-backup` (на стенде) **до остановки центра** проверить, что свежий дамп БД получен и места на
   целевом диске хватает на дамп + состояние; при нехватке — отказ без остановки центра. Изменение скрипта — в отчёт (diff).
2. Запустить полную копию вручную: результат (код, длительность, простой центра, размер) — в отчёт;
   `checkpoint.py verify` по копии — ок. При отказе — текст причины (теперь он конкретный).

## 4. Сверка нового Web с макетами (браузер)
Открыть `https://10.170.108.2:8090`, войти (пароль вводит пользователь). Пройти все пункты меню: Системы (список,
карточка системы, карточка компонента, «Хосты вне систем», мастер «Новая система…» — до шага 3, не сохранять),
Здоровье (оба разреза), Компоненты, Хосты (+ карточка хоста .5), Схема сети (L3, L2, Площадки), Разбор конфликтов,
Источники, Обследования сети, Portable-аудит, Мои задачи, Обращения (Очередь, Каталог услуг, Календарь, SLA), Склад,
Оргструктура, Уведомления, общий поиск.

Для каждого экрана — скриншот (1600×1000 или полный экран, без паролей) и список отличий от макетов C53
(холст макетов: https://claude.ai/artifact/7usgK1Z9MpsFe3Phe774pb). Уже известные отличия и что исправлено —
`docs/plans/surveyscan-v2/handoffs/c53-web-audit-20-11.md`; отмечать: «исправлено на стенде» / «осталось» / «новое».

## 3. Collector через deb из сети (повтор раздела 2 №27, Astra 10.170.108.11)
1. Web: код «collector площадки», 1 установка. deb (0.0.0~c28) — скачать из Web (теперь работает) и перенести на Astra.
2. `sudo apt install ./surveyscan-collector_*.deb` → служба inactive.
3. Неверный отпечаток: `echo <код> | sudo surveyscan-collector-setup --center https://10.170.108.2:<порт> --fingerprint <64×«ab»>
   --listen 0.0.0.0:8444` → отказ до отправки кода; в Web код «0 из 1».
4. Верный отпечаток — тем же способом; **пусть пользователь один раз введёт код вручную** (запустить setup без `echo`, в
   терминале Astra): ввод не отображается (№120). → «служба … запущена», в Web — второй collector активен.
5. `sudo apt install --reinstall ./…deb` — служба перезапущена, источник тот же.
6. Затем спросить пользователя: оставить или `sudo apt purge surveyscan-collector` (по умолчанию — purge).

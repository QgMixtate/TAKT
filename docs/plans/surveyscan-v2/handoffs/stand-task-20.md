Меню: Системы, Здоровье, Компоненты, Хосты, Схема сети, Разбор конфликтов; Источники, Обследования сети,

1. **Хосты:** число «всего» = числу активов в реестре; дерево по площадке/команде/системе/ОС со счётчиками; фильтр по
   свежести; сортировка по «Сбор»; выгрузка CSV открывается в Excel; «Собрать сейчас» на .5 — цель получила запрос.
2. **Системы:** завести (с «да») систему «Стенд» мастером «Новая система…» (меню «Действия»): среда Прод, компоненты

   сейчас» → предложения в «Хосты вне систем», подтвердить. Карточка системы: состав, «Требует внимания», изменения.

4. **Здоровье:** оба разреза (направление и площадка), «только не зелёные / все», у хоста — причины цвета.

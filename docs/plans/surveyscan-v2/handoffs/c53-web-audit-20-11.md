# Сверка нового Web с макетами C53 (20.11, демо-стенд, 1600×1000)

Снимки: `web/scripts/audit_shots.mjs` (`SURVEYSCAN_AUDIT=1 scripts/demo_stand.py <out>`), 21 экран.

## Общие (на всех вкладках)
1. Плотность крупнее макета: меню 232 px (макет 208), шапка 56 px (48), шрифт таблиц/меню 14 px (13), полоса счётчиков 15 px (13–14).
2. Порядок «полоса счётчиков → вкладки» в макете; в Обращениях, Обследованиях, Складе — наоборот.
3. Глобальный поиск сохраняет запрос после ухода со страницы поиска.
4. Карточка обращения (диалог) не закрывается Esc и остаётся поверх при смене вкладки/раздела.

## По вкладкам
- Компоненты: группа системы дублируется (сортировка по среде, а не по системе); имена компонентов не ссылки; нет «Представление»/чипов фильтра.
- Хосты: свежесть «нет сведений» у хостов, которые в карточке «данные актуальны»; в «Ответственный» сырое `fallback`.
- Схема сети: над картой KPI-карточки и большая легенда — в макете дерево + карта + паспорт без них.
- Здоровье: кнопки разрезов обрезаны («Направление → система → …»).
- Источники: «Обновить» отдельной строкой над полосой; форма «Установка по коду» не в панели, «Создать код» не основная кнопка; нет колонок «Что/сколько», «Площадка», нет панели выбранного источника.
- Обследования: вкладки без счётчиков; пустая правая панель.
- Portable-аудит: в макете 3 коротких шага + зона перетаскивания; у нас длинные команды на экране, обычный input file.
- Мои задачи: нет приветствия и строки «вы отвечаете за…»; «Обращения на мне» висит «Загрузка…», KPI «…».
- Обращения: в макете таблица + карточка справа; у нас карточка — модальное окно; «Каталог услуг» в макете вместе с SLA и календарём.
- Склад: полоса под вкладками; нет предпросмотра акта.
- Поиск: нет фильтров «Площадка/Состояние»; красная плашка «полнотекстовый поиск недоступен» на демо.
- Хосты вне систем: чекбокс правила смещён; импорт — textarea вместо зоны перетаскивания.
- Мастер системы: нет «Сохранить черновик»; правило привязки — select вместо текста правила.
- Разбор конфликтов: полоса по типам (дубли MAC/серийный, IP, несопоставленные, решено) — у нас «открыто/разобрано/отложено»; нет фильтров тип/площадка.
- Системы, карточка системы, карточка компонента, карточка хоста, Оргструктура, Уведомления — по структуре совпадают; отличия только общие (п. 1).

## Задача
1. **Токены.** Все цвета — только через `var(--…)`: дочистить `theme.css`, перенести нужное из `style.css` и
   удалить его, цвета схемы сети (`topology.tsx`, в т.ч. экспорт SVG) — из токенов. Семантика, а не цвет:
   `--bg`, `--surface`, `--surface-2`, `--line`, `--text`, `--text-2`, `--muted`, `--accent`, `--accent-soft`,
   `--secondary`, `--ok/--warn/--bad` (+ `-soft`), `--sidebar-*`, `--focus`.
2. **Темы** (набор — подтвердить у пользователя):
   - «Светлая» — текущая, эталон макетов;
   - «Тёмная» — те же бренд-цвета, фон/панели тёмные, маджента и синий подобраны по контрасту;
   - «Системная» — по настройке ОС (по умолчанию);
   - кандидаты: «Высокий контраст» (АРМ дежурных, проекторы), «Ночная смена» (приглушённая тёмная для NOC).
   Переключение: `data-theme` на `<html>`, выбор в меню аккаунта; хранить в профиле пользователя на сервере
   (перенос между АРМ), до входа — `localStorage`/ОС. Экран входа уважает выбор.
3. **Светофор и статусы** различимы во всех темах и без цвета (форма/подпись) — критично для «Здоровья», РСМ,
   схемы сети; контраст текста ≥ 4.5:1 (WCAG AA) — проверять скриптом.
4. **Брендирование под заказчика (вопрос):** логотип и акцентный цвет организации поверх темы (white-label для
   интеграторов) — только с решения пользователя; C03 не затрагивает.
5. **Проверка:** снимки всех разделов × тем × 1440/1280 px (Playwright, как в C53), e2e без изменений, CI web зелёный.

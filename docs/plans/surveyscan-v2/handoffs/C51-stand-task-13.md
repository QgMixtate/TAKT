# Задание №13 для локального Claude (стенд awm.local): выделенные учётки сбора, отключение цели DC и файловых служб

**Запускать после того, как облачная сессия подтвердит зелёный hosted CI на коммите выкладки Web** (указывается в
сообщении облачной сессии). Центр и collector остаются на `70f62e7` (миграций не добавлялось) — меняется только Web
(кнопка «Отключить/Включить» у учётки сбора). Текст задания читать с `origin/develop`.

Решения пользователя (2026-11-14): перейти на **выделенные учётки** (вместо личной `ar`); цель `.1` на DC —
**отключить**; прежние **файловые службы целей — отключить сейчас** (файлы учёток оставить на неделю для отката);
«CA домена» и GPO — не сейчас. Вывод пустого актива `9252d8db` из учёта — функции в продукте пока нет (вопрос
пользователю задан отдельно), актив не трогать.

Правила: sudo — только по подтверждению пользователя, временный sudoers удалить в конце; пароли и ключи вводит
**пользователь сам в Web** — в чат, файлы и журналы они не попадают; Claude ключ `collect_ed25519` не читает;
DC — только чтение; изменения на win-ar — только с подтверждения пользователя.

## 1. Копия и Web
- Свежая копия: `surveyscan-stand-backup.service` + `checkpoint.py verify` — OK (без неё не продолжать).
- Web из коммита выкладки: чистый worktree, `npm ci && npm run generate && npm run build`, выложить в `~/ss-web`
  (в архиве путь `web/dist`); `version.json` — коммит выкладки. Ctrl+F5. На вкладке «Учётки сбора» у каждой учётки
  есть кнопка «Отключить».

## 2. Подготовка учёток на узлах (проверка, без изменений, кроме win-ar с подтверждения)
- `.5`, `.7`: у `scanprobe` есть открытый ключ из пары `collect_ed25519` в `authorized_keys` (как в задании №8);
  проверить входом с ВМ стенда: `ssh -i /etc/surveyscan-targets/collect_ed25519 -o BatchMode=yes scanprobe@<адрес> true`
  (sudo для чтения ключа — по подтверждению; ключ не выводить).
- win-ar (пользователь, «от администратора», с подтверждения): `prepare-winrm-target.ps1 -Account AWM\scanwinrm
  -Collector 10.170.108.2 -Kerberos` — идемпотентен; добавит `AWM\scanwinrm` в группы удалённого управления и DCOM,
  права WMI, проверит HTTP-прослушиватель и Kerberos. Вывод — в отчёт (без секретов).

## 3. Учётки в Web (вводит пользователь)
«Обследования сети» → «Учётки сбора» → «+ Новая учётка»:
- SSH «Linux RO»: логин `scanprobe`, способ «Закрытый ключ» — содержимое `/etc/surveyscan-targets/collect_ed25519`;
- WinRM «Windows RO»: логин `AWM\scanwinrm`, пароль.
Если такие учётки уже заведены (№11) — повторно не заводить.

## 4. Перевод целей на выделенные учётки
У цели нельзя сменить учётку: старая цель отключается, новая создаётся. Для каждого узла по очереди:
1. «Цели сбора» → у старой цели (учётка `ar`) «Отключить».
2. «Подсети» → узел → «Собирать…»:
   - `.5` и `.7` — SSH, «Linux RO», отпечаток пустой;
   - `.10` — WinRM, «Подключение: HTTP 5985 + Kerberos», «Полное имя ПК» `win-ar.awm.local`, «Windows RO».
3. Ждать «собрано» (до ~3 мин). При ошибке — текст колонки «Состояние» и хвост журнала collector (`target_…`).
4. Проверить: данные пришли в **тот же** актив (simple2fa, calc-dep, win-ar), дублей и конфликтов нет; на win-ar
   событие 4624 для `AWM\scanwinrm` с IpAddress 10.170.108.2 — пакет **Kerberos**.
После всех трёх: на «Учётки сбора» отключить учётки на `ar` («вся», «win») — у них должно остаться 0 активных целей.

## 5. Цель DC
«Цели сбора» → SSH-цель `10.170.108.1:22` → «Отключить». Пустой актив `9252d8db` не трогать.

## 6. Файловые службы целей (sudo по подтверждению)
1. Сопоставить каждую службу `surveyscan-ssh-*` / `surveyscan-winrm-*` с адресом цели (файл конфигурации службы;
   учётки и ключи не выводить) — в отчёт таблицей «служба → адрес → есть ли активная Web-цель с данными».
2. Остановить и отключить (`systemctl disable --now …`) службы, у адреса которых есть активная Web-цель со
   свежими данными (`.5`, `.7`, `.10`), и службу цели `.1` (DC, отключаем). Остальные — не трогать, в отчёт.
3. Файлы учёток служб **не удалять** (откат); записать, что их можно удалить после недели работы из Web.
4. Через 10 минут: Web-цели продолжают доставку; источники отключённых служб ожидаемо станут «давно не было
   контакта» — это не ошибка (отметить в отчёте).

## 7. Отчёт (одним сообщением, без секретов)
Копия; коммит Web; вывод скрипта на win-ar; цели до/после (адрес, способ, учётка, состояние, первый сбор);
дубли/конфликты (0); событие 4624 для scanwinrm — Kerberos?; отключённые учётки и цели; таблица служб и что
отключено; `pilot_report.py`; удалён ли временный sudoers; замечания по Web.

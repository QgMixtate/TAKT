# Задание №30 для локального Claude (стенд awm.local): повтор мастера portable после №29, вывод источников, уборка

**Этап:** C52.04, последняя проверка перед приёмкой. **Решения пользователя (27.11):** правило брандмауэра центра не
сохранять (после перезагрузки ВМ его нет — восстановить по OPERATIONS §16 п. 4); исправления мастера №133–139 —
проверить коротким повтором на win-ar.

**Правила — как в №29.** Ничего вне 10.170.108.0/24; DC — только чтение. Пароли вводит пользователь сам в мастере —
не в чат, отчёт и файлы. Действия вне задания — только с «да» пользователя.

## 1. Выкладка
Последний `develop` с зелёным CI (не раньше коммита с этим заданием). Выпуск **0.0.0-c30** как в №29, перезапуск центра с
`--release-dir …/stage-c30/…`. Журнал: «файлы установки: выпуск 0.0.0-c30 … true». Правило iptables на месте:
`iptables -L INPUT -n -v --line-numbers` — `DROP … !lo !10.170.108.0/24 dpt:<порт>`; если ВМ перезагружалась — поставить
заново **с `! -i lo`** (показать пользователю, «да»). Web открывается, collector стенда шлёт наблюдения.

## 2. Вывод замолчавших источников (№131)
Пользователь: «Источники» → `125c7683…` → «Вывести из работы» → «заменён новой установкой»; `a73c8a4d…` → «выведен из
эксплуатации». Проверить: состояние «отозван», счётчик «агентов молчат > 24 ч» уменьшился, карточки win-ar и Astra — те же активы.

## 3. Мастер на win-ar (пользователь ведёт, Claude проверяет центр)
1. Web «Portable-аудит» → «Копировать строку»: строка в буфере, либо выделена с подсказкой «Ctrl+C» (№133).
2. Скачать `surveyscan-portable_0.0.0-c30_windows_x64.exe` на win-ar в новый каталог-носитель, `wizard --state .\ss-portable`.
   В шапке — **«версия 0.0.0-c30»** (№139).
3. Шаг 1 — строка → «Подготовить носитель» → блок в Web «Зарегистрировать носитель».
4. Шаг 2 — `10.170.108.0/24`, «Начать обследование»: подсети и скорость **остаются введёнными** (№134).
5. Шаг 3 — профиль SSH `linux-ro`, правило Linux → linux-ro; поправить поле и **один раз** нажать «Сохранить и дальше» —
   мастер переходит на шаг 4 (№135). На шаге 4 у узлов «нет правила» — подсказка «добавьте правило на шаге 3».
6. Шаг 4 — «Собрать выбранные»: `.6` — **«вход отклонён / второй фактор»** (№136); страница узла с частичным сбором —
   «ещё на N узле/узлах» (№137).
7. Шаг 5 → загрузить пакет в Web: при выборе файла прежний итог исчезает, новый итог — с именем файла (№138). Хостов не больше,
   чем до загрузки.
8. Отзыв пользователя о мастере — дословно.

## 4. Уборка (список — в отчёт перед удалением, удалять с «да»)
ВМ центра: `/tmp/t29`, `/tmp/t30`; ПК пользователя: каталог-носитель `t29\usb`; win-ar: `.\ss-portable` с пакетами №29 и №30
(после загрузки). Носитель ПК `0099ac7e…` (без загрузок) — пользователь выводит из работы кнопкой.

шагов 3–5), итог импорта, хосты до/после, отзыв пользователя, что убрано. Новые замечания — с №140.

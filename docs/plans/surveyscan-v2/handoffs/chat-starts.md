# Стартовые сообщения для чатов по этапам (решение пользователя 25.11)

Правило: **один чат — один этап**. Отчёты стенда — в чат этапа, к которому относится задание. Общие вопросы («что
дальше», план) — в отдельный короткий чат «План». Каждый чат начинает с чтения `docs/STATUS.md` (раздел «Сейчас» и
«Следующие шаги»), `docs/plans/surveyscan-v2/pilot/ISSUES.md` (открытые) и документа своего этапа. Порядок этапов —
в STATUS; этапы выполняются **поочерёдно**, следующий не начинается, пока предыдущий не принят пользователем.

Общие правила для всех чатов (повторены в CLAUDE.md/AGENTS.md): ответы короткие, по-русски; секреты в чат и репозиторий
не класть; счётчик плана и статусы пакетов — только с приёмки пользователя; теги не пушить; main — только fast-forward
после приёмки; команды на ВМ стенда выполняет локальный Claude пользователя по заданию (handoffs), изменения на узлах —
только с «да» пользователя; C03 заморожен; миграции — только следующим номером (сдвигать фикстуру update_smoke и счётчики).

# C52.04 — установщики, скачивание из Web, мастер portable: что принято (27.11)

**Принято пользователем 27.11 («1 принимаем»).** Решение — [C52](C52-rust-agents-and-installers.md), разделы C52.04, C52.08.

| AC | Что есть | Где проверено |
|---|---|---|
| C52-04 MSI | агент и collector: тихая установка `COLLECTOR_URL/CENTER_URL`, `CENTER_FINGERPRINT`, `REG_CODE` (скрыт из журнала), откат при ошибке регистрации, без кода служба не стартует, обновление сохраняет регистрацию, `REMOVE_DATA=1`, правило брандмауэра collector | CI Windows Server 2022 (msi_check.ps1); стенд №27 (win-ar — тот же актив) |
| C52-05 deb/rpm | nfpm, служба не стартует до регистрации, `*-setup` со скрытым вводом и проверкой вида кода, `register.env` для Ansible, обновление и purge | CI контейнеры 8 дистрибутивов + systemd; стенд №27–28 (Astra, collector из сети) |
| C52-06 коды | N установок, просрочка, отзыв, неверный отпечаток — отказ до отправки кода | integration, стенд №28 |
| C52-07 скачивание | «Источники → Установка → Скачать»: SHA-256 по подписанному manifest выпуска, админ/оператор, аудит `installer.downloaded`, проверка SHA-256 в браузере | integration, smoke, стенд №28 |
| C52-08 стенд | MSI на win-ar, collector deb на Astra, portable с носителя — прежние активы без дублей (хостов 8 → 8) | стенд №27–30 |
| Мастер portable | макеты версии 2: строка подготовки из Web, 5 шагов, «Только проблемы», страница узла («почему», «как исправить», «Повторить узел»), шрифты в exe, запуск двойным щелчком | CI (portable_wizard.mjs в Chromium), стенд №29–30 (win-ar) |

Замечания стенда №118–142 — исправлены или решены пользователем (ISSUES). Вне объёма: подпись Authenticode (C52.05 —
нет), удаление Go-агента и Go-portable — отдельным решением (C52.02).

## Отзыв пользователя
«не нравится что portable необходимо поднимать через powershell» → запуск двойным щелчком по exe (или ярлыку), без
установки; носитель — `ss-portable` рядом с программой (сделано при приёмке).

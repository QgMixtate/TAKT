# C53 + C54 — что сдаётся на приёмку (26.11)

Этапы, добавленные решением пользователя 19.11: **C53** — новый интерфейс ТАКТ.Каталог по макетам
([C53](C53-web-visual-and-brand.md), макеты 1–12, вариант 1); **C54** — ресурсно-сервисная модель
([C54](C54-rsm.md)): направление → система → среда → компонент → хост. Статусы и счётчик плана меняются только
приёмкой пользователя.

## Отклонения от макетов (сознательно)
- Метрики CPU/диск/службы и график в «Здоровье» — с C55 (мониторинга ещё нет); выдуманных чисел нет.
- Кнопок без функций нет: «Подтвердить и заглушить», «Отправить тестовое», «Мои устройства», предпросмотр «правило
  найдёт хостов» — до появления API.
- «Разбор конфликтов» — без фильтра «Площадка» (у конфликта нет площадки в API).
- Карточка хоста — добавлена вкладка «Учёт и связи» (функции прежней карточки).

## Не входит / открыто (не мешает приёмке)
- №99 (P4) — модель оборудования по WinRM; №87 — срок хранения сырых наблюдений — отдельной задачей после приёмки.
- №111 (стенд) — хранение unseal-ключа и root-токена OpenBao; решение пользователя.
- Последние исправления №108–110, №113 (26.11) проверены в CI/smoke; на стенде — смотрятся при приёмке.

## Как принять
1. Стенд: выкладка последнего `develop` (CI зелёный) — центр, collector, Web.
2. Пройти разделы по таблице выше в браузере (стенд или демо-стенд `scripts/demo_stand.py`).
3. Решение: «C53/C54 принято» или список замечаний. После приёмки — следующий этап C52.04 (отдельный чат).
